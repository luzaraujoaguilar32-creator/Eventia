Inteligencia artificial

En esta carpeta se desarrollará la conexión de Eventia con el servicio de inteligencia artificial que se utilizará en el proyecto.

Aquí se seleccionará el proveedor y el modelo de IA que se utilizarán para interpretar las preguntas de los usuarios y generar respuestas relacionadas con la organización de eventos.

En el archivo provider.py se realizará la configuración necesaria para establecer la comunicación con el proveedor seleccionado.

También se desarrollará el proceso mediante el cual el asistente recibirá los mensajes del usuario, identificará qué información necesita consultar y utilizará las herramientas MCP correspondientes para obtener los datos.

La información que se proporcione al asistente deberá respetar los permisos y el tipo de cuenta del usuario.
