# Cliente MCP
Implementar aquí el cliente MCP en Python que:
1. Se conecte al servidor MCP configurado.
2. Descubra herramientas disponibles.
3. Envíe argumentos validados.
4. Devuelva resultados estructurados al servicio de IA.
5. Maneje errores, desconexiones y tiempos de espera.

No enviar credenciales ni confiar en argumentos de identidad proporcionados por el modelo.
