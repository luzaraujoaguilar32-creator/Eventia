# Pruebas y evidencias
Registrar fecha, responsable, escenario, datos de prueba, resultado esperado, resultado obtenido y evidencia.

## Casos mínimos
- Registro e inicio de sesión válidos e inválidos.
- Cliente no puede consultar reservaciones de otro cliente.
- Personal administrativo puede operar solo las funciones autorizadas.
- Administrador puede gestionar usuarios y roles.
- Consulta real a PostgreSQL y MongoDB.
- Descubrimiento e invocación de las seis herramientas MCP.
- Disponibilidad bloquea horarios ocupados.
- Cotización calcula correctamente subtotales y total.
- Stripe en modo de prueba y webhook con firma válida/inválida.
- Manejo de errores y servicios no disponibles.
